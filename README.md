# Phantom Tracker

Developed a Python-based cyber crime investigation simulator to analyze suspicious banking transactions using searching and sorting algorithms.

## Features
- Linear Search for detecting suspicious transactions
- Selection Sort for organizing transaction records
- Binary Search for identifying target transactions
- Merge Sort for reconstructing complete transaction history
- Time complexity analysis of algorithms

## Technologies Used
- Python
- Data Structures & Algorithms

## Algorithms Used
- Linear Search
- Binary Search
- Selection Sort
- Merge Sort
